# Login / Signup Static Webpage

A small responsive Login/Signup UI built with plain HTML, CSS and JavaScript.

## Run locally

Open `index.html` directly in a browser, or use VS Code Live Server.

## Deploy on Render

1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. In Render, choose **New + → Static Site**.
4. Connect your GitHub repository.
5. Build Command: leave empty.
6. Publish Directory: `.`
7. Click **Create Static Site**.

This is a frontend-only demo. It does not store users or authenticate against a database.
